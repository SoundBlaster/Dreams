# Редактор параметрических штрихов

Рабочий конвейер: **параметры → контур → SVG**. Генерация изображений не участвует.

## Запуск

```sh
make katakana
python3 -m http.server 8767 --bind 127.0.0.1 --directory research/glyphs/build/katakana
```

Открой `http://127.0.0.1:8767/editor.html`. Если сервер уже работает на этом порту,
достаточно пересобрать страницу и обновить вкладку. Готовый `editor.html` также
самодостаточен: все данные и JavaScript встроены, внешних CDN/API нет. Для стабильного
browser storage предпочтителен постоянный localhost URL. Ссылка есть в каталоге.

## Как править

1. Выбери знак, затем штрих и его участок. Серые точки на траектории выбирают
   участки; цветные — начало, середина, конец текущего участка.
2. Перетаскивай цветные точки или задавай X/Y числами. Середина находится **на
   дуге** при t=0.5. Прямая использует только начало и конец. Для крючка/поворота
   добавь участок; ненужный можно удалить. Соседние участки сохраняют общую точку.
3. Задай максимальную толщину и её положение по **длине всего штриха**.
   Начальная и конечная толщины ограничены максимумом. Между ними используется
   плавная C1-интерполяция, без выбросов и ступенек. На стыке участков траектория
   сохраняет C0-связность; повороты не принудительно сглаживаются.
4. Выбери острое или тупое начало/окончание независимо. Острое сводит ширину к нулю,
   тупое оставляет срез поперёк траектории. Слайдер соответствующей толщины при
   остром окончании выключен, но его значение сохранено для возврата к тупому.
5. Ширина всего знака меняет его вытянутость, отражение применяется к готовому
   контуру. Смотри превью 20/26/32/48 CSS px без свечения. Это SVG preview,
   не FreeType/Metal и не окончательная проверка шрифта на дисплее.

Смена знака сохраняет его параметры. Undo/Redo действует на редактирование,
добавление/удаление штриха, сброс и импорт. История — до 40 действий в текущей
вкладке; сам проект автоматически сохраняется между перезагрузками. Новую
латинскую/кириллическую букву можно добавить по символу и построить из штрихов.
Готовые наборы латиницы/кириллицы пока не переведены в эту параметрическую модель.

## Сохранение и экспорт

- **Сохранить JSON** — все знаки и параметры; это основная переносимая копия.
- **Открыть JSON** — загрузить файл проекта. **Вставить JSON** — тот же импорт
  через текстовое поле, если системный файловый диалог недоступен.
- Неправильный формат, нечисловые координаты, разрывы участков, дубликаты знаков,
  нулевые штрихи и превышение лимитов отклоняются до замены проекта.
- **Экспорт SVG** — текущий знак с отражением и пропорциями, группа `id="glyph"`,
  viewBox `0 0 956 1024` и сохранённая атрибуция. Контур состоит из заполненных
  перекрывающихся участков с nonzero fill; штатный SVG loader объединяет их.
  JSON остаётся источником редактируемых параметров. Обратный импорт произвольного
  SVG в управляемые штрихи не реализован.
- Browser storage не заменяет JSON-копию: он привязан к браузеру и origin.

## Начальные данные и ограничения

46 знаков посеяны из направленных катаканных этюдов. Кубические centerlines
приближаются короткими квадратичными участками с проверкой отклонения в четвертях
кривой (порог 0.15 единицы). Профиль ширины редактора упрощён до начала/максимума/
конца; это новый инструмент дизайна, а не точная копия эллиптической кисти каталога.
Окончания пера и финальную форму пользователь задаёт через траекторию/ширину.
Ни один исходный знак не объявлен эталоном киношрифта.

[атрибуцию KanjiVG / CC BY-SA 3.0](NOTICE.md). Экспорт не устанавливает шрифт
и не меняет ресурсы приложения.

## Проверено

- `make katakana-check`: 27 Python tests, поведение старого каталога, 8 новых
  проверок геометрии/данных и event/state suite редактора.
- Две сборки каталога, включая редактор, совпадают побайтно.
- 92 экспортированных SVG читаются и объединяются существующим SVG loader;
  площади обычных и отражённых контуров совпадают в пределах 2%.
- Safari/CUA: числовые координаты, слайдер максимума, отражение, Undo/Redo,
  восстановление после reload, загрузка JSON через вставку и отмена импорта.
- Реально скачанные JSON/SVG проверены с диска: SVG совпадает с геометрией
  скачанного JSON, включая внесённые изменения.
- Native pointer drag не подтверждён: CUA возвращает `noWindowsAvailable`.
  Преобразование координат отражённого drag и его Undo проверены event-тестом
  с DOM double; это не замена физической проверке перетаскивания в браузере.
- File picker в управляемом Safari показывает JSON, но оставляет Upload
  недоступным даже без accept-фильтра. Импорт вставкой проходит; успешное открытие
  через системный диалог пока не подтверждено.
