# План восстановления Matrix glyphs

Цель: воспроизводимый каталог форм из пользовательского видео, затем проверенный набор для Dreams. Первые 20 знаков имеют постоянные ID G01–G20. Смена гипотезы о символе не меняет ID.

## 1. Каталог и идентификация — текущий этап

- [x] Сохранить референсы из временных вложений в `references/`.
- [x] Зафиксировать последнюю реконструкцию `restored-v5.png` и координаты исходных вырезок `provenance.json`.
- [x] Разобрать все 20 форм: символ, Unicode при уверенном соответствии, отражение/поворот, альтернативы, уровень уверенности.
- [x] Сверить заключения субагента с кадрами и подтверждениями пользователя.
- [x] Отметить недостающие формы из дополнительных кадров отдельной очередью, не подменяя текущие ID.

Результат: `identifications.json`, `IDENTIFICATIONS.md`, локальный `catalog.html`. Значение confidence относится к идентификации знака, а не к качеству восстановленного контура. Подтверждения пользователя сильнее предположений модели.

## 2. Восстановление небольшими партиями

- [ ] Начать с форм с высокой уверенностью, затем разбирать спорные по одной.
- [ ] Передавать GPT Image исходный кадр, реальный символ и явно указанное преобразование. Для неизвестного знака использовать геометрическое описание.
- [ ] Править по 1–4 глифа за итерацию; сохранять предыдущую версию и точный промпт.
- [ ] Сохранять чистые контуры без glow, зерна и намеренных повреждений. Светлое пересечение штрихов не является отверстием.
- [ ] Проверять, что вне целевых глифов нет незапрошенных изменений.

Результат: версия каждого глифа, основание правки, сравнение с референсом. Генерация — визуальная гипотеза, а не доказательство оригинального начертания.

## 3. Редактируемые векторы и контроль формы

Инструмент этапа — [PIPELINE.md](PIPELINE.md): `pipeline.py build` даёт `build/glyphs/Gxx.svg` (настоящие paths в единицах шрифта), `adopt` переносит контур в ручную правку, проверки топологии, совпадения с листом и ориентации по фильму запускаются при каждой сборке.

- [x] Подготовить отдельные SVG с настоящими редактируемыми paths для ручной доводки пользователем; растровый референс держать отдельно. Не выдавать встроенный PNG за вектор.
- [ ] Передать простые контуры с умеренным количеством узлов и одинаковой системой координат; сохранять исходные версии.
- [ ] Учесть последние правки: излом перекладины G04, направление лапки G06 по фильму, отражение G15.
- [ ] Проверить количество штрихов, связность, настоящие просветы и отдельные акценты.
- [ ] Проверить отражение и ориентацию; G01 — зеркальная 5, G02 — перечёркнутый 0.
- [ ] Сравнить в одинаковом физическом размере, отдельно с минимальным свечением.
- [ ] Подобрать общий шаг ячейки и базовую линию, сохраняя естественный размер коротких знаков.
- [ ] Проверить чтение на реальном размере дождя и плотность соседних столбцов.

Критерий перехода: нет известных ложных дыр, обрезанных частей или подменённых знаков; спорные формы явно помечены, а не выданы за подтверждённые.

## 4. Atlas и проба в Dreams

- [ ] Собрать версионированный atlas и метаданные, сохранив текущий набор для сравнения.
- [ ] Подключить экспериментальный набор отдельной опцией.
- [ ] Проверить печать сверху вниз, одиночные замены и отсутствие возврата затухших строк.
- [ ] Сравнить короткий видеорендер с фильмом; после этого выбирать основной набор.

## 5. TTF/OTF и расширение

- [ ] При необходимости обвести проверенные формы и собрать шрифт.
- [ ] Назначать cmap только проверенным символам; неизвестным киношным формам дать внутренние ID или документированные PUA-коды.
- [ ] Дорисовать согласованные латиницу и кириллицу для keywords отдельно от реконструкции знаков фильма.
- [ ] Указать происхождение каждого контура и проверить права на используемые исходные шрифты перед распространением.

## Рабочий цикл

`reference → hypothesis → reconstruction → visual review → accepted asset`

Субагент Sol 6.1 / Medium ведёт идентификацию и готовит точечные reconstruction briefs. Основной агент проверяет результаты, интегрирует каталог и изменения приложения. Новые партии можно поручать тому же субагенту. Сам по себе субагент не продолжает работу после завершения назначенного задания.

Референсы `film-reference-*.jpg` и `g17-clear.jpg` — кадры пользователя. `hypothetical-table.jpg` — только иллюстрация желаемого каталога: её подписи Unicode и формы не считаются доказательством. Спецификации Unicode используются для проверки идентичности символов, а не как источник копируемых контуров шрифта.
