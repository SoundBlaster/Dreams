# Dreams TV release decisions

## Self-created DreamsMatrix font — 2026-10-27

The owner states that DreamsMatrix was created for this project rather than
imported as a ready-made font from a film rightsholder. The existing
[reconstruction provenance](../../research/glyphs/PIPELINE.md) remains intact:
a generated reference sheet, editable contours and subsequent manual work form
the input to the local font pipeline. The owner authorizes release with the
current font and accepts the possibility of a rights complaint.

The internal release gate requiring a separate pre-release redistribution-rights
review for this font is closed by this owner decision. An unsolicited permission
request to a film studio is not a required project step. No outside clearance,
license from a film rightsholder or legal determination is recorded. The decision
does not establish how a dispute would be resolved or change Apple's intellectual
property requirements. See [App Review Guideline5.2](https://developer.apple.com/app-store/review/guidelines/#intellectual-property).

If a complaint is received, the owner's intended response is to remove the
contested material and replace it with an independently designed version; the
owner suggested a repertoire without katakana. This is a future response plan,
not a promise that removing a writing system by itself resolves every possible
claim. No glyphs or fonts are changed by this decision.

This decision concerns DreamsMatrix. Matrix-Code.ttf remains a separate bundled
resource covered by its existing MIT notice in
[third-party notices](../../THIRD_PARTY_NOTICES.md). All copied-source notices,
provenance and historical records are preserved. No blanket ownership claim is
made for third-party material.

No App Store Connect content-rights declaration is changed here. The prepared
IPA and its bundled notices remain byte-identical to the recorded archive. Build
upload, review submission and public release remain separate actions.
